## 1. 지시 · 완료 정의 · 범위

- **지시 요약**: 「일단 커스텀으로 뺴고 원주는 넘어가고 지금 내가 기존에 줬던 의회 3개에서 원주를 뺴고 해보자」 「이게 가능하면 다 돌리고 비고로 뺴면 되니까」 → 홍성군의회(41016)·충청북도의회(43001)·단양군의회(43003)를 주며 「이거 3개로해줘」, 「아니 내가 지금까지 주는것들은 다 배정+사전 허용이야」(사용자, 2026-10-16). 사전 허용으로 SSOT 6장·14장 순서대로 저장·추가수집까지 하고 결과 문서를 보낸다(CLAUDE.md 1절).
- **완료 정의**: 대상 기관·유형마다 수집 시각 기준 대수별(의안 외는 1~50페이지 범위) 사이트 건수 = 수집이력 로그의 수집 건수이고, 필드 대조에서 빠지거나 틀린 필드가 없다(SSOT 6장 8단계). 다르면 사유와 이월처를 적는다. 공통 수집기로 안 되면 판정을 '보류: 수집기 보완'으로 하고 7절 '커스텀 후보'에 적는다(SSOT 13장).
- **사전조건**: O 표시 실측, 배정 확인(SSOT 0장 라운드 표·10장 담당 칸), 로그인은 사람이 직접, 화면 상단 '데이터베이스 선택' 확인.

## 3. 건수·필드 대조 (D4) — 기준 건수 먼저 고정

- 추가 수집 **전에** 사이트 건수·사이트 실측 근거·기준 고정 시각(YYYY-MM-DD HH:MM)을 먼저 적는다.
- 수집 직전에 다시 센다. 값이 같으면 기준 고정 시각을 재확인 시각으로 바꾼다. 다르면 사이트 건수·기준 고정 시각을 재확인 값으로 바꾸고 사유 칸에 「재확인: 이전 값 n건(시각)」을 적는다.
- 대수별(의안 외는 1~50페이지 범위 — SSOT 9장 8번 해석)로 따로 적고 **합산하지 않는다**. 같은 대수를 다시 수집했으면 회차를 늘려 새 줄로 적는다.
- 수집 건수는 그 회차의 수집 건수다(다시 수집하면 새로 수집 — SSOT 9장 12번 답의 해석, 사람 확정 아님). 실측으로 확인되기 전까지 재수집 회차의 판정에는 '(잠정: 9장 12번)'을 붙인다. 다르게 보이면 사유 칸에 적는다.
- 차이가 0이면 사유 칸은 '해당 없음'.
- 차이가 수집 시각 이후에 등록된 글 때문이면 그 근거(등록일)를 적는다.
- 사이트 실측 근거: 목록 URL, 대수 선택값, 캡처 파일명(캡처는 `evidence/Rnn/`, 저장소에 올리지 않음). 못 셌으면 사유.

**필드 대조** — 수집이력 목록의 회차 행 › 상세 › [수집데이터 보기](화면 구성 미확인, SSOT 14.5)에서 번호를 하나씩 눌러 원본 상세(상세 링크·'바로가기', 다른 탭)와 1:1로 대조한다(SSOT 6장 8단계).

- 범위는 대수별 표본 3건(첫·중간·마지막 페이지에서 1건씩)이고, 값이 드문 필드나 첨부가 있는 건을 따로 더한다(SSOT 9장 13번 답, 6장 8단계). 4절 정규식 샘플과 같은 건을 쓴다.
- 대조한 표본은 건마다 한 줄로 적는다(첫·중간·마지막 페이지 건이라 번호가 이어지지 않는다). 모든 필드가 맞으면 결과 칸에 '일치'를 적고, 빠지거나 틀린 필드가 있으면 그 칸에 '수집값 → 원본 값'으로 적는다.
- 화면에 보이지 않는 컬럼은 '화면에 없음'으로 적고 9절 '미검증'에도 남긴다. DB 대조는 지금 하지 않는다(SSOT 6장 8단계).
- 첨부는 내려받아 열리는지와 확장자를 본다(SSOT 6장 8단계). 내려받기는 사람 확인 뒤, 파일은 `evidence/Rnn/`에만 둔다. 표본 건의 첨부만 내려받는다(SSOT 9장 13번 답). 첨부가 없는 건은 '해당 없음'.
- '수집데이터 보기'의 저장은 누르지 않는다. 한 건을 다 보면 뒤로 가기로 돌아간다.
- 빠진 필드는 대수별 4장 샘플 범위까지 모은 뒤 그 컬럼 정규식만 고쳐(5절) D3 수집테스트를 거쳐 다시 추가 수집하고, 새 회차로 이 표에 다시 적는다. 사람이 직접 짠 정규식으로도 안 되면(SSOT 4장 '고치는 순서') 7절 '커스텀 후보'로 넘긴다.

- 설정 저장·추가 수집은 건별로 사람 확인을 받은 뒤 실행하고 '사람 확인' 칸에 확인한 사람을 적는다. 이 라운드가 CLAUDE.md 1절 사전 허용 범위에 들면 묻지 않고 실행하고 '사람 확인' 칸에 '사전 허용(날짜)'을 적는다. 코드 변환(매핑)은 담당이 저장하지 않고 누락 목록만 요청한다(SSOT 6장 9단계).
- 실행 직전 DB 선택값이 의정포털 개발DB가 아니면 실행하지 않는다(SSOT 8장 작업 DB, 9장 9번 답). [추가수집]은 ☐ 기존데이터 삭제가 해제일 때만 누른다(SSOT 14.3). 누르는 버튼과 순서는 SSOT 14장을 따른다.
- '정규식 패턴 JSON 입력'으로 정규식을 넣는 것도 설정 저장이다. 고치는 컬럼은 전→후를 적는다. '수집 규칙 JSON 입력' 창에 처음 채워진 내용 전체를 'JSON 표기'로 '전'에 남기고(SSOT 4장 '정규식 패턴 JSON 입력', 14.4 4번), [적용] 뒤와 저장 뒤에 고치지 않은 컬럼이 그대로인지 확인해 적는다.
- 수집이력 '수집데이터 보기'의 저장은 누르지 않는다(SSOT 6장 8단계). 눌렀으면 시각과 경위를 이 표에 적고 사람에게 알린다.
